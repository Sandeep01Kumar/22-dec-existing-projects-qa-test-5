# hao-backprop-test

A simple Hello World HTTP server built with Python 3 and Flask. Test project for backprop integration.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

The server will start at `http://127.0.0.1:3000/`.
